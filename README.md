
🤖 Simple AI Chatbot

A beginner-friendly AI chatbot developed using HTML, CSS, and JavaScript. This chatbot provides instant responses to user queries using predefined input patterns and keyword matching.

📌 Project Overview

This project demonstrates how to create a simple chatbot that can interact with users through a website interface. It is designed for basic customer support and information sharing.

✨ Features

* Interactive chatbot interface
* Instant responses to user queries
* Predefined questions and answers
* Keyword-based response system
* User-friendly design
* Press Enter to send messages
* No external libraries required

🛠️ Technologies Used

* HTML – Structure of the chatbot
* CSS – Styling and layout
* JavaScript – Chatbot logic and responses

💬 Sample Questions

* Hi
* What is your name?
* How can you help me?
* What are your working hours?
* How can I contact you?
* What is the price?
* Where are you located?
* How can I register?
* Thank you
* Bye

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `chatbot.html` in any web browser.
4. Type a question in the chat box.
5. Click the Send button or press Enter.
